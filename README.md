# DAILY-THANTHI-NEWS-WEBSITE
The Daily Thanthi News Website is a responsive news portal web application inspired by the structure and layout of Daily Thanthi.
This project is developed for educational purposes to demonstrate frontend development skills, structured content layout, and responsive news portal design.
The website displays categorized news articles such as Tamil Nadu, India, World, Sports, Business, and Entertainment with a clean and organized interface.
🚀 Features
🗞️ Latest News Section
📂 Category-Based News (Tamil Nadu, India, World, Sports, etc.)
🔍 Search Bar (if implemented)
📱 Fully Responsive Design (Mobile, Tablet & Desktop)
🖼️ News Images with Headlines
📄 Detailed News Article Page
🌐 Smooth Navigation Menu
🛠️ Technologies Used
HTML5
CSS3
JavaScript (if applicable)
Flexbox / CSS Grid
Responsive Web Design
🎯 Project Objective
The objective of this project is to replicate a professional news website layout and improve skills in:
Content structuring
Responsive layouts
UI/UX design
Multi-section page organization
